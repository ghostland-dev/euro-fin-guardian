# Mali: Personal Finance

[![CI](https://github.com/ghostland-dev/euro-fin-guardian/actions/workflows/ci.yml/badge.svg)](https://github.com/ghostland-dev/euro-fin-guardian/actions/workflows/ci.yml)

Personal finance SaaS (Arabic UI): budget, debts, goals and investments.

## Features

- Budget and debt tracking
- Savings goals and investments
- Reports

## Tech Stack

- Vite
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)
- TanStack Query
- React Router

## Getting Started

```bash
git clone https://github.com/ghostland-dev/euro-fin-guardian.git
cd euro-fin-guardian
npm install
npm run dev
```

Other scripts:

- `npm run build`: vite build
- `npm run lint`: eslint .
- `npm run preview`: vite preview
